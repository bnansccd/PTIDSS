## 1. 背景与目标

对照 PRD/SRS 全量需求逐条核查生产系统（前端 15 页面 + 后端 22 Controller/约 90 端点 + 52 张 PG 表 + 8 张 TDengine 超级表），发现"需求已写入文档但系统未实现/未呈现"的差距集中在**前端呈现层**与**个别人机协同闭环**。本轮依据四份设计文档，按 7 角色（admin/manager/trader/auditor/operator/viewer/analyst）权限矩阵对生产系统做全面核查，并完成修复与回归。

### 3.3 浏览器实测发现的 2 个契约 Bug（回归中修复）

1. **/review 列表渲染崩溃**：后端 `summary` 返回扁平对象 `{period,revenue,...}`，前端按 `[{label,value}]` 数组处理 → `items.slice is not a function`。修复：前端 `toSummaryItems()` 统一兼容对象/数组两种形态，嵌套值 JSON 化展示（杜绝 `[object Object]`）。
2. **/trade 持仓 Tab 崩溃**：后端 `GET /trade/positions` 返回 `{longTerm:[96], spot:[96], net:[96]}` 对象，前端按数组 `.map()` → TypeError。修复：`normalizePositions()` 归一化为行数组（T01~T96），SVG 画 net 净值曲线，表格全量 96 行 + 滚动容器。
