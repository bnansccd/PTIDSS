# 一、产品概述

## 1.1 项目背景

随着电力市场化改革深入推进，依据《电力现货市场基本规则（试行）》（发改能源规〔2023〕1217号）、《关于加快建设全国统一电力市场体系的指导意见》（发改体改〔2022〕118号）以及《关于完善全国统一电力市场体系的实施意见》（国办发〔2026〕4号）等政策要求，全国统一电力市场体系建设加速：现货市场2027年前基本实现正式运行，中长期市场实现带曲线连续运营，2030年市场化交易电量占全社会用电量约70%。截至2024年底，全国注册参与交易经营主体达81.6万家，较2016年增长18倍。

交易主体面临的挑战日益凸显：

1. **决策依赖经验**：发电功率、电价、负荷波动剧烈，多市场多周期并行，人工经验决策难以适应高频交易节奏；
2. **预测能力不足**：缺乏高精度发电功率、电价、负荷预测能力，交易报价缺乏数据与模型支撑；
3. **多市场协同难**：中长期与现货、省内与省间市场互相影响，缺乏多市场联合优化手段，存在结构性收益损耗；
4. **结算复盘繁重**：结算单据多、口径复杂，人工核对效率低、易出错，复盘缺少数据化手段；
5. **数据孤岛**：市场、交易、结算数据分散，缺乏统一管理，与公司营销管理平台数据未打通；
6. **合规与风险压力**：市场限价、偏差考核、信息披露、市场力监测等规则日趋细化，交易合规与风险防控要求显著提升。

## 1.2 建设目标

建设一套以 **AI 大模型预测与多智能体决策为核心引擎**的电力交易智能辅助决策系统，实现：

- **G1 预测智能化**：完成发电功率、电价、负荷预测大模型训练与开发，为交易决策提供高精度预测底座；
- **G2 决策智能化**：研发多智能体决策、多市场联合优化算法，覆盖中长期（日滚动、短期合同转让）、省内现货、省间现货全场景交易决策；
- **G3 平台一体化**：搭建智能交易辅助决策平台，集成多智能体协同模块、人机协同界面、预测模型，完成系统调优与移动端小程序建设；
- **G4 业务闭环化**：形成「预测 → 决策 → 交易 → 复盘 → 结算」业务闭环，并实现与公司电力营销管理平台数据互通；
- **G5 合规稳健化**：建立政策研判、规则库、合规校验与风险防控机制，支撑市场干预、信息披露与考核应对。

## 1.3 产品定位

面向电力交易业务人员的**智能交易辅助决策平台**，是连接「市场数据 → AI 模型 → 交易决策 → 结算复盘」的一体化工作台。产品坚持**人机协同、辅助决策**定位：AI 出策略、人做决策，关键决策人工确认后执行，决策全链路可解释、可追溯。

## 1.4 建设范围

系统包含四大核心模块（政策与数据、智能交易辅助决策、复盘与结算、数据管理），一个智能决策底座（预测大模型 + 多智能体 + 联合优化算法），一个平台载体（智能交易辅助决策平台 + 移动端小程序），以及系统集成（对接公司电力营销管理平台，统筹双端数据互通费用）。

## 2.3 市场环境研判（对标依据）

- **现货市场**：山西、广东等6省现货市场转入正式运行，19省现货市场和南方区域电力市场开展试运行；现货市场2027年前基本实现正式运行；
- **中长期市场**：实现带曲线连续运营，覆盖年度（多年）、月度、月内（多日）等周期，连续开市、不间断交易；
- **经营主体**：截至2024年底注册经营主体81.6万家，燃煤机组全部进入市场，超半数新能源参与市场；
- **新兴市场**：绿证市场、容量市场、零售市场、辅助服务市场（16省调峰、15省调频）加速建设。

## 3.2 国内研究与产业进展

- **华北电力大学**：面向山东现货市场规则（限价±50%、新能源优先消纳）的改进型MADDPG竞价算法，独立储能竞价收益较规则式策略高27%；
- **浙江大学**：博弈论+Transformer竞价模型，山西现货市场VPP报价中标率提升19%，价格预测误差较LSTM降低8%；
- **清华大学**：多区域协同竞价AI框架，优化省间套利与省内交易报价，省间交易损耗降低15%（长三角市场仿真验证）；
- **国内产业**：主流能源信息化厂商已推出交易辅助决策产品，覆盖预测、报价、结算、复盘等功能，但普遍存在“预测与决策割裂、多市场联合优化能力弱、人机协同体验不足”等短板——本系统以“预测-决策一体化 + 多智能体协同 + 多市场联合优化 + 人机协同”为差异化定位。

## 3.3 对标结论

1. 预测是基础：负荷/新能源/电价高精度预测（逐小时、分钟级、置信区间）是国际成熟产品共同底座；
2. 决策是核心：强化学习/博弈论驱动的多智能体报价与多市场协同是收益提升关键（国际案例收益提升22%~115%）；
3. 回测与迭代是保障：策略需在历史数据上持续回测、周/月级更新迭代；
4. 人机协同是合规底线：国内市场规则差异化强，辅助决策+人工确认模式更适配国内交易环境。

# 四、用户角色与使用场景

## 4.1 角色矩阵

| 角色 | 使用场景 | 核心诉求 | 使用终端 |
|---|---|---|---|
| 交易员 | 日常交易申报、报价决策、合同管理 | 快速获得可执行策略与报价建议 | 平台 + 小程序 |
| 市场分析师 | 政策研判、行情分析、预测结果解读 | 政策影响研判、趋势判断、预测可信度 | 平台 |
| 结算专责 | 结算单核对、偏差分析、结算报表 | 自动核对、异常预警、报表自动生成 | 平台 |
| 数据管理员 | 数据维护、接口管理、数据质量监控 | 自动录入、全流程可追溯 | 平台 |
| 决策管理者 | 成效分析、交易考核、复盘报告审阅 | 直观成效看板、考核指标、复盘结论 | 平台 + 小程序 |
| 合规与风控 | 规则校验、风险防控、信息披露 | 合规检查、风险预警、可审计留痕 | 平台 |
| 移动用户 | 出差/非办公场所关注行情、接收预警 | 行情速览、预警提醒、移动审批 | 小程序 |

## 4.2 核心用户旅程（交易员日滚动交易）

1. 早间查看系统推送的次日负荷/电价预测与市场行情摘要；
2. 系统基于中长期持仓与预测结果生成日滚动调整策略建议（含多方案对比）；
3. 交易员在人机协同界面审阅策略、调整参数、确认报价方案；
4. 系统按交易中心规则生成申报文件并提交；
5. 交易执行后，系统自动归集成交结果，纳入持仓管理；
6. 月度结算后，系统自动生成结算分析报告与成效复盘。

## 5.1 业务架构

```
┌─────────────────────────────────────────────────────────┐
│                    智能交易辅助决策平台                     │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │

├─────────────────────────────────────────────────────────┤

└─────────────────────────────────────────────────────────┘
```

## 5.2 应用架构

- **展现层**：桌面端平台（人机协同工作台）、移动端小程序、可视化大屏；
- **应用层**：四大核心模块 + 平台服务（预警、消息、审批、报表引擎、规则引擎）；
- **算法层**：发电功率/电价/负荷预测大模型、多智能体决策框架、多市场联合优化引擎、策略回测引擎；
- **数据层**：数据采集（营销平台、交易中心、气象）、数据仓库、数据治理与血缘；
- **基础设施层**：服务器、GPU算力、安全防护（等保三级）、容灾备份。

## 5.3 技术架构

- **前端**：Web端主流框架（Vue/React）+ 可视化组件库；小程序跨端框架；
- **后端**：微服务架构（Spring Cloud/分布式服务），消息队列支撑异步任务（预测、优化求解）；
- **算法**：Python技术栈（PyTorch/TensorFlow）训练预测大模型；数学规划求解器（Gurobi/CPLEX或开源求解器）支撑联合优化；
- **多智能体**：LLM + 强化学习 + 规则引擎混合框架，智能体间协商/仲裁机制；
- **数据**：关系库（交易数据）+ 时序库（负荷/电价序列）+ 大数据平台（数据仓库）；
- **部署**：私有化部署，支持信创/国产化适配，满足电力行业安全合规要求。

## 5.4 数据架构

- **数据来源**：电力营销管理平台（市场/交易/结算数据）、交易中心公开数据、气象数据、调度运行数据；
- **数据分层**：原始层 → 明细层 → 汇总层 → 应用层；
- **数据流向**：采集 → 清洗 → 入库 → 特征工程 → 模型预测 → 决策引擎 → 结果回流 → 复盘沉淀；
- **数据治理**：主数据管理、数据标准、数据质量规则、血缘追踪、全流程留痕；
- **数据安全**：分级分类、脱敏、加密存储与传输、访问审计。

## 5.5 集成架构

- **电力营销管理平台**：标准接口（API/文件交换）双向交互市场、交易、结算数据，双端一致性校验；
- **电力交易中心**：交易公告、出清结果、申报回执数据对接；
- **气象数据源**：数值天气预报（预测模型输入）；
- **统一身份认证**：与公司统一认证体系对接（SSO）。

# 七、详细功能需求

## 7.1 政策与数据模块

### 7.1.1 政策研判 FR-PD-01（P0）

**需求描述**：对电力市场相关政策、交易规则、考核办法进行数字化解析与影响研判，辅助业务人员快速理解政策变化并评估对交易策略的影响。

**功能详述**：
1. 政策库管理：政策文件上传、分类（国家/区域/省内）、标签化管理、版本管理；
2. 政策智能解析：基于 NLP 大模型对政策文件结构化解析，抽取关键条款（交易规则、价格机制、考核条款、结算规则）；
3. 影响研判：将政策条款与历史交易数据关联，输出「政策变化点 → 影响环节 → 影响程度」研判结论；
4. 规则库沉淀：解析后的规则条款自动沉淀为可配置规则，供合规校验与决策引擎引用；
5. 政策推送：政策更新时向相关角色推送摘要与解读；
6. 政策日历：关键时间节点（申报窗口、结算窗口、考核节点）日历化提醒。

**业务规则**：
- 政策原文与解析结果双屏对照展示，解析内容标注置信度；
- 政策变化影响研判需生成可追溯的分析记录。

**验收要点**：支持不少于 500 份政策文件入库管理；政策解析准确率不低于 85%；研判结论可一键生成简报；规则沉淀可被合规校验复用。

### 7.1.2 市场数据分析 FR-PD-02（P0）

**需求描述**：汇聚市场行情、供需、价格等数据，提供多维度可视化分析，支撑市场趋势判断。

**功能详述**：
1. 行情看板：省内/省间现货价格、中长期成交价格、供需形势等实时/历史展示；
2. 多维度分析：按时间（日/周/月/年）、品种（中长期/现货）、市场（省内/省间）钻取分析；
3. 价格特征分析：峰谷价差、价格波动率、出清价格分布、历史同期对比；
4. 供需分析：负荷需求、可用发电能力、新能源出力、备用情况分析；
5. 市场力与异常监测：价格异动、供需紧张、报价异常等场景自动预警；
6. 自定义报表：分析师可按需配置分析视图与报表。

**验收要点**：主要行情指标刷新延迟不超过 15 分钟；支持不少于 3 年历史数据回溯分析。

### 7.1.3 智能市场预测 FR-PD-03（P0，AI核心）

**需求描述**：完成**发电功率、电价、负荷预测大模型**的训练、开发与部署，为交易决策提供高精度预测底座。

**功能详述**：
1. **发电功率预测大模型**：
   - 覆盖火电、水电、风电、光伏等电源类型；
   - 输入：气象预报、历史出力、设备状态、检修计划等；
   - 输出：未来 1-7 天（可至 15 分钟粒度）发电功率预测曲线及置信区间；
2. **电价预测大模型**：
   - 覆盖省内日前/实时、省间现货价格预测；
   - 输入：负荷预测、供需形势、新能源出力预测、历史价格、检修计划等；
   - 输出：未来 1-7 天各时段（96点）价格预测与区间；
3. **负荷预测大模型**：
   - 输入：历史负荷、气象、日历特征（节假日）、经济因素等；
   - 输出：未来 1-7 天负荷曲线预测；
4. **模型管理**：模型版本管理、训练任务管理、效果评估（滚动回测）、模型上线/回滚；
5. **预测结果可视化**：预测曲线与历史实际曲线对比、误差展示、置信区间展示。

**算法指标要求**（验收核心）：

| 预测对象 | 指标 | 目标值 |
|---|---|---|
| 发电功率（次日96点） | MAPE（平均绝对百分比误差） | ≤ 5%（火电）；风电/光伏达到行业先进水平 |
| 电价（日前96点） | MAPE | ≤ 15%，峰谷时段方向准确率 ≥ 90% |
| 负荷（次日96点） | MAPE | ≤ 3% |
| 预测时效 | 单次全场景预测计算时长 | ≤ 10 分钟 |

**业务规则**：
- 预测模型支持定期自动重训（每日增量更新、每周全量重训）；
- 预测结果必须附带置信度/误差区间，供决策引擎引用。

## 7.2 智能交易辅助决策模块

### 7.2.1 中长期交易决策（日滚动）FR-TR-01（P0）

**需求描述**：在中长期交易框架内，基于最新预测与市场行情，按日滚动优化次日交易计划，支撑交易员快速调整中长期持仓与申报。

**功能详述**：
1. 持仓管理：中长期合同电量、曲线、剩余执行进度实时可视化；
2. 日滚动优化：以「预测负荷/功率 + 现货价格预测 + 中长期持仓」为输入，求解次日电量与曲线的最优调整方案；
3. 多方案对比：输出基准方案、保守方案、进取方案等多套申报建议，标注各方案预期收益与风险；
4. 申报辅助：按交易规则生成申报表单、电量/曲线数据文件；
5. 结果跟踪：申报结果、成交结果自动回填，更新持仓。

**业务规则**：
- 优化目标：中长期合同收益 + 现货预期收益 - 偏差考核成本，最大化综合收益；
- 约束：发电能力、检修计划、合同约束（最小/最大交易量）、交易规则限制。

**验收要点**：日滚动优化求解时长 ≤ 5 分钟；策略建议均附带可解释的理由与风险提示。

### 7.2.2 短期合同转让 FR-TR-02（P1）

**需求描述**：支撑短期合同转让（含受让/出让）的定价分析与决策。

**功能详述**：
1. 转让机会识别：结合自身持仓与市场行情，识别转让空间（盈余/缺口）；
2. 定价建议：基于现货价格预测与对手方行为，给出转让价格区间建议；
3. 转让方案生成：生成拟转让电量、时段、价格方案，支持多方案模拟；
4. 转让记录管理：转让合同台账、执行情况跟踪。

**验收要点**：转让定价建议区间与市场实际成交价偏差可量化评估；方案模拟支持不少于 3 套情景。

### 7.2.3 省内现货交易决策 FR-TR-03（P0）

**需求描述**：支撑省内日前、实时现货市场的报价决策。

**功能详述**：
1. 报价决策：基于发电成本曲线、价格预测、风险偏好，生成分段报价策略（量价曲线），申报段数/限价适配本省规则；
2. 情景模拟：对出清价格不同情景进行收益模拟，输出期望收益与风险分布（CVaR 等）；
3. 报价单生成：按交易中心格式生成报价申报文件；
4. 出清结果分析：成交电量、价格、阻塞情况分析；
5. 实时市场辅助：基于实时偏差，提供实时市场申报/调整建议。

**验收要点**：报价建议生成 ≤ 3 分钟；报价策略含风险度量指标（CVaR/最大回撤）；申报段数、限价参数可配置。

### 7.2.4 省间现货交易决策 FR-TR-04（P1）

**需求描述**：支撑省间现货交易的申报与决策，统筹省内/省间市场衔接。

**功能详述**：
1. 省间行情分析：省间价格、通道可用容量、送受电形势分析；
2. 省间报价决策：综合考虑省内供需、省间价差、通道约束，生成送受电报价策略；
3. 跨市场衔接：省内与省间申报的一致性校验与协同建议；
4. 结果跟踪：成交情况、通道占用、结算影响分析。

**验收要点**：省间报价建议考虑通道约束与省内平衡约束；跨市场协同建议可解释。

### 7.2.5 多智能体协同决策 FR-TR-05（P0，AI核心）

**需求描述**：研发多智能体决策框架，将交易决策拆分为多个专业智能体（预测、报价、风险、结算、合规、复盘智能体等），通过协同机制形成全局最优决策。

**功能详述**：
1. 智能体编排：定义各智能体的职责、输入输出、协作流程；
2. 协同机制：支持竞争/协商/投票等协同策略，汇聚各智能体结论形成最终策略；
3. 决策推理：基于大模型 + 规则引擎 + 优化算法混合推理，输出可解释的决策依据；
4. 智能体管理：智能体运行监控、效果评估、参数调优；
5. 人机确认机制：关键决策由人审阅确认后方可执行（辅助决策定位）。

**业务规则**：
- 多智能体决策结果必须输出决策依据链（每个智能体的输入、判断、置信度）；
- 各智能体结论冲突时，由仲裁机制（如综合评分）决定，并记录冲突处理过程。

**验收要点**：智能体数量不少于 6 个；决策全链路可回溯、可解释；人机协同确认流程完整。

### 7.2.6 多市场联合优化 FR-TR-06（P0，AI核心）

**需求描述**：研发多市场联合优化算法，统筹中长期、省内现货、省间现货多市场，实现全局收益最优。

**功能详述**：
1. 联合优化模型：建立覆盖多市场、多周期、多约束的统一优化模型；
2. 滚动优化：按日滚动更新预测与约束，输出未来 N 日的最优交易组合方案；
3. 灵敏度分析：价格、负荷、出力的不确定性对方案的影响分析；
4. 方案对比与仿真：多方案收益仿真、风险仿真对比；
5. 策略回测：历史数据回测验证，支持策略库沉淀。

**业务规则**：
- 模型需支持中长期合同电量分解与现货市场的耦合约束；
- 不确定性处理：采用随机优化/鲁棒优化方法，输出稳健方案。

**验收要点**：联合优化方案收益相对单市场分步决策基准提升可量化（回测）；求解时效满足交易窗口要求。

## 7.3 复盘与结算模块

### 7.3.1 智能复盘 FR-RS-01（P0）

**需求描述**：对交易决策与执行结果进行自动化复盘，形成「决策-结果-原因-改进」闭环。

**功能详述**：
1. 复盘看板：交易收益、成交情况、预测偏差、策略执行偏差总览；
2. 偏差归因：预测偏差（发电/电价/负荷）、决策偏差（报价 vs 最优）、执行偏差（申报 vs 成交）分层归因；
3. 策略评估：各策略的历史效果对比，识别有效策略与失效场景；
4. 复盘报告：自动生成周/月复盘报告，含图表与改进建议；
5. 复盘知识沉淀：将复盘结论沉淀为策略库/规则库，反哺决策引擎。

**验收要点**：复盘报告一键生成；偏差归因覆盖预测、决策、执行三个层面；复盘结论可回流至策略库。

### 7.3.2 结算分析 FR-RS-02（P0）

**需求描述**：对结算数据进行分析与核对，支撑结算争议处理与成本控制。

**功能详述**：
1. 结算数据核对：系统结算数据 vs 交易中心结算单自动核对，差异预警；
2. 结算结构分析：电能量费用、偏差考核、辅助服务、输配电价等费用结构拆解；
3. 分时结算分析：峰谷时段收益贡献分析，指导后续交易；
4. 结算异常预警：异常费用、异常电量自动识别与告警；
5. 结算台账：结算周期、金额、状态全记录。

**验收要点**：结算核对自动化率 ≥ 95%；差异项自动生成处理工单；费用结构拆解支持多维度钻取。

**验收要点**：考核规则配置化；考核结果自动计算、可追溯、可申诉。

## 7.5 智能交易辅助决策平台

### 7.5.1 多智能体协同模块集成 FR-PL-01（P0）

**需求描述**：将多智能体协同模块与平台一体化集成，形成统一的决策能力服务。

**功能详述**：
1. 服务化集成：多智能体协同决策以服务形式供各业务模块调用；
2. 统一调度：决策任务统一调度、排队、执行、监控；
3. 结果分发：决策结果按业务场景分发至对应模块；
4. 运行监控：智能体运行状态、耗时、成功率监控大盘。

**验收要点**：集成后各模块调用决策服务平均响应满足业务时效；监控大盘实时可见。

### 7.5.2 人机协同界面 FR-PL-02（P0）

**需求描述**：打造交易员友好的决策工作台，实现「AI 建议、人工决策」的顺畅协同。

**功能详述**：
1. 决策工作台：策略建议、依据解释、风险提示、人工确认/修改/驳回的一站式界面；
2. 可视化决策流：策略生成过程（智能体结论 → 汇聚 → 建议）可视化；
3. 方案对比交互：多方案并排对比、参数微调、收益风险联动刷新；
4. 操作便捷性：常用操作快捷键、批量操作、模板化操作；
5. 界面个性化：布局、看板组件按角色自定义。

**验收要点**：核心决策流程（查看建议→调整→确认→申报）操作 ≤ 5 步；关键操作均有日志。

### 7.5.3 平台与预测模型集成 FR-PL-03（P0）

**需求描述**：将预测大模型输出与平台业务模块无缝集成。

**功能详述**：
1. 预测服务化：预测模型以标准 API 提供服务，供决策、复盘、成效分析调用；
2. 结果订阅：业务模块按需订阅预测结果，实时/定时获取；
3. 预测缓存与版本管理：预测结果版本化存储，支持结果追溯；
4. 异常处理：预测服务异常时的降级策略（使用上一版本预测结果并告警）。

**验收要点**：预测 API 可用性 ≥ 99.5%；预测结果版本可追溯。

### 7.5.4 系统调优 FR-PL-04（P1）

**需求描述**：持续开展系统性能与算法效果调优，保障系统稳定高效运行。

**功能详述**：
1. 性能调优：接口响应、报表生成、模型推理性能监测与优化；
2. 算法调优：模型参数、优化求解参数、智能体参数的迭代优化；
3. 调优机制：调优任务管理、效果对比（A/B）、发布回滚。

**验收要点**：关键页面 P95 响应 ≤ 3 秒；调优过程可记录、效果可对比。

### 7.5.5 移动端小程序 FR-PL-05（P1）

**需求描述**：建设移动端小程序，支撑交易业务移动化办公。

**功能详述**：

2. 预警推送：价格异动、预测偏差、结算异常、考核提醒等消息推送；
3. 决策审批：移动端完成策略确认、申报审批；
4. 复盘摘要：复盘报告移动端查看与分享；
5. 个人中心：账户、消息、订阅设置。

**验收要点**：小程序与平台数据实时同步；预警消息到达延迟 ≤ 1 分钟；支持主流机型适配。

# 十一、业务规则与核心流程

## 11.1 交易决策主流程

```
市场数据采集 → 预测模型（发电/电价/负荷）→ 多智能体协同分析
  → 多市场联合优化 → 策略建议生成（多方案）→ 人机协同确认
  → 申报执行 → 成交结果归集 → 复盘沉淀 → 策略库更新
```

## 11.2 日滚动优化流程

1. 每日 T-1 日 16:00 前完成次日预测更新；
2. 读取中长期持仓与合同约束；
3. 运行日滚动优化模型，输出多方案；
4. 交易员确认/调整后生成申报文件；
5. 申报结果回填，持仓更新。

## 11.3 结算核对流程

1. 结算周期结束后自动拉取结算单；
2. 结算单智能识别入库；
3. 与系统结算数据自动核对；
4. 差异项生成工单并预警；
5. 人工处理差异并留痕。

## 11.4 复盘与考核闭环

复盘（偏差归因）→ 策略库更新 → 下一周期决策引用 → 成效分析 → 考核评分 → 管理改进。

## 11.5 合规与风险防控流程

1. 规则库实时校验：申报前自动校验申报段数、限价、持仓比例等合规约束；
2. 风险预警：价格异动、偏差风险、市场力风险自动预警；
3. 应急处置：配合市场干预与应急处置预案，保留全量操作留痕。

# 十三、风险分析与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| 预测精度不达标 | 决策效果受影响 | 预留模型迭代窗口、多模型集成、滚动重训 |
| 数据源接入延迟/缺失 | 预测与决策时效受影响 | 数据质量监控与手工补录兜底机制 |
| 营销平台接口口径差异 | 数据一致性风险 | 早期接口调研与口径对齐，建立核对机制 |
| 交易规则频繁调整 | 决策算法失效 | 规则参数化配置，算法快速适配 |
| 省间/省内市场规则差异大 | 算法适配成本高 | 规则抽象层 + 分省策略模板 |
| 双端费用超支 | 项目成本风险 | 费用测算前置、边界清单化、统筹管理 |
| 专业人才短缺 | 建设质量风险 | 专家驻场 + 知识转移 + 培训体系 |
| 监管政策变化（如市场干预） | 业务连续性风险 | 应急处置预案、操作留痕、合规智能体 |
