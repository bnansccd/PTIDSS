# PTIDSS 操作手册（V1.7）

> 适用版本：V1.7（2026-08-20）｜系统：电力交易智能辅助决策系统
> 访问入口：`http://<host>/`（生产经 nginx）；开发态 `http://<host>:30001/`

## 1. 登录与账号

### 1.1 登录

1. 打开系统首页，输入账号密码，填写图形验证码，点击登录；
2. 初始账号（生产首启后请立即修改默认密码 `Ptidss@2026`）：

| 账号 | 角色 | 说明 |
|---|---|---|
| admin | 管理员 | 全部菜单与接口权限 |
| trader01 | 交易员 + 移动审批 | 申报/行情/决策/政策/消息/预测/优化 + 移动端菜单 |
| settle01 | 结算员 | 结算/审批流/消息 |
| manager01 | 经理 | 数据底座/审批流/优化/复盘/报表/消息 |

### 1.2 令牌与自动续期

- 登录令牌有效 120 分钟；剩余不足 10 分钟时系统**自动调用 `/auth/refresh` 滑动续期**，页面无感，无需重新登录；
- 关闭浏览器/刷新页面（F5）后无需重新登录（已接入用户态恢复）；
- 退出登录请点击右上角「退出」，系统会通知后端注销令牌（令牌立即失效）。

### 1.3 区域切换

- 多省配置化：江苏（CN-32）/ 上海（CN-31）/ 浙江（CN-33）已启用；
- 顶部区域下拉切换后，全站行情/交易/结算等数据按该省口径展示（`X-Region-Code` 请求头路由）；
- 账号须有对应区域授权（系统管理 → 用户 → 区域授权），否则切换受限。

## 3. 核心业务操作

### 3.1 市场行情（交易员）

1. 进入「市场行情」→ 选择市场类型（现货/中长期）、交易阶段（日前/实时/滚动）；
2. 时间范围必填，格式 `yyyy-MM-dd HH:mm:ss`（如 `2026-08-20 00:00:00`）；
3. 查看成交价/成交量列表与趋势，支持分页浏览（pageNo/pageSize 由系统处理）。

### 3.2 交易申报（交易员）

1. 「交易申报」→ 新建申报方案 → 填写分时段电量与价格（受合规规则约束：申报段数 ≤10、价格 0~1500 元/MWh、持仓比例 ≤30%）；
2. 提交前系统自动执行合规预检（RULE-DECL-SEG / RULE-PRICE-LIM / RULE-POS-RATIO），违规项高亮提示；
3. 方案提交后进入审批流（如配置），由经理/移动端审批。

### 3.3 结算管理（结算员）

1. 「结算管理」→ 结算记录：按周期核对系统结算与交易中心结算（口径：自然月/交易月随区域配置）；
2. 差异核对：发现差异生成工单（金额差异/缺记录/多记录）；
3. 台账关账：开账 → 确认 → 关账；
4. OCR 识别：上传结算单图片自动识别，低置信度进入人工复核。

### 3.4 情报中心与推送规则（交易员/分析师/合规）

1. 情报流：按重要度（high/medium/low）与类型筛选，全国情报 + 当前省情报可见；
2. 推送规则：新建规则（规则名/匹配标签/重要度/目标角色）——匹配口径：情报标签与规则标签**交集非空**且重要度一致；
3. 渠道自动分配：重要度 high → web+sms+miniapp；其余 → web；
4. 系统每 30s 自动执行推送（high 级实时语义）；也可在列表页手动「立即执行」；
5. 已推送情报在个人「消息中心」可见（类型：情报推送），`biz_ref` 幂等保证不重复。

### 3.5 数据底座（经理/合规/管理员）

1. 数据源台账：营销/交易中心/气象三类源，双通道（rest/sftp）配置查看；
2. 采集任务：按类型（market/settlement/weather）手动触发，`force=true` 强制重跑；定时任务按 `cron_expr` 自动执行（V1.7，每分钟检查）；
3. 质量报告：完整率/准确率/及时率按规则聚合；
4. 血缘：数据源 → 采集 → 明细 → 指标 → 模型/报表 全链路节点查询。

### 3.6 系统管理（管理员）

1. 用户管理：新增/停用账号、分配角色（固定 7 类编码，不可新建自定义角色）、区域授权；
2. 角色管理：仅可修改描述与状态（角色编码受 DDL CHECK 约束固定 7 类）；
3. 权限管理：菜单/接口/数据三级权限查看与关联；
4. 区域管理：区域启用/停用、市场支持类型（现货/中长期/省间）、通道配置（rest/sftp/both）；
5. 审计日志：登录/操作留痕查询。

## 4. 常见问题

| 现象 | 处置 |
|---|---|
| 验证码不显示 | 确认生产 profile（验证码默认开启）；测试态 `CAPTCHA_ENABLED=false` 时登录页不展示验证码属正常 |
| 登录报「账号或密码错误」 | 确认账号状态 active；默认密码首登后已修改；可联系管理员重置 |
| 菜单缺失 | 该角色未授权对应权限码（如交易员无「系统管理」）；权限关联见系统管理→角色 |
| 情报推送未收到 | 检查推送规则 active、情报未推送（push_status=none）、标签有交集、目标角色下有用户；等待 ≤30s 或手动执行 |
| 页面数据为空 | 检查当前区域：切换区域后数据按省口径展示；全国数据不随区域过滤 |
| F5 刷新被登出 | 确认使用 V1.7 前端（已接入用户态恢复与令牌续期）；清理浏览器缓存后重试 |
| 时间查询报错 | 时间参数必须 `yyyy-MM-dd HH:mm:ss`（空格分隔），勿传 `T` 分隔 ISO 格式 |

## 5. 运维提示

- 数据备份：`pg_dump -h 127.0.0.1 -U ptidss -d ptidss -F c -f ptidss_$(date +%Y%m%d).dump`；
- 日志：`logs/ptidss.log`（prod）按日滚动，保留 30 天；
- 健康检查：`GET /ptidss/auth/captcha` 返回验证码图片即后端存活；状态脚本 `deploy/scripts/status.sh`；
- 生产密钥：`TOKEN_SECRET` 变更会使全部存量令牌失效（全员需重新登录），请谨慎操作并提前通知。
