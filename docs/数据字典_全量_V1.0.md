# 电力交易智能辅助决策系统 全量数据字典

**（V1.1，配套开发基线 V1.6 · 第 5.6 节展开；2026-08-08 评审决议同步；DDL v1.0.1 勘误批次 DDL-ERR-2026-001 已执行同步）**

| 项目 | 内容 |
|---|---|
| 依据 | 开发基线 5.1 核心数据实体总表 / 5.6 数据字典样例 / SRS 9.2 评审决议 |
| 版本 | V1.1 |
| 编写 | 数据组 + 开发组（评审版：DDL 基线 v1.0 评审通过后同步锁定） |
| 通用约定 | ①所有业务表含 `id`（雪花 BIGINT）、`created_at`/`updated_at`（TIMESTAMP）、`version`（INT 乐观锁，默认 1）、`deleted`（BOOLEAN 软删除，默认 false）；②金额 `NUMERIC(18,4)` 元、电量 `NUMERIC(18,4)` MWh、价格 `NUMERIC(12,4)` 元/MWh、功率 `NUMERIC(12,4)` MW；③时间统一 TIMESTAMP（北京时间），日粒度 `DATE`；④曲线类 JSONB；⑤通用字段不再逐表重复列出（仅标注"含通用字段"）；⑥region_code 为配置化多省编码（评审决议：多省扩展 P0，支撑全国推广），交易/结算/报表按 region_code 隔离；⑦结算周期口径由配置项 settlement.periodMode 决定（natural_month 自然月/trading_month 交易月），台账与报表按所选口径生成，历史周期按原口径归档；⑧交易中心对接支持 REST 与文件交换双通道（配置项 exchange.channel，REST 默认、SFTP 兜底），data_source.connect_config 按通道分别建模 |

## 一、市场数据域
