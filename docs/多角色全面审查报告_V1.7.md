## 2. 技术架构审查结论

**通过**，基线架构一致：

- 后端分层（controller/service/mapper/domain）与 DDL 基线、数据字典 V1.0 一致；雪花 ID 应用层生成（`id-type: none`）；
- 统一响应 `{code,message,data,traceId,success}` + 错误码体系（14001/14003/500）前后端一致；
- 令牌：JWT（120min）+ Caffeine 缓存（130min）+ 滑动续期（剩余 <10min），V1.7 补齐 `POST /auth/refresh` 契约缺口；
- 权限：方法级 AOP `@RequiresPermissions` + 前端菜单过滤双保险；21 项权限码与种子一致；
- 分页：契约/后端/前端统一 `pageNo/pageSize`（修复前端 7 处 `page` 误传）；
- 时间格式：全链路 `yyyy-MM-dd HH:mm:ss`（契约 pattern 已声明，修复 /market/** 6 处 ISO 声明）。
